Política de Privacidade

GymTracker - última atualização: 29 de junho de 2026

Esta política explica como o GymTracker coleta, usa e protege informações quando você usa o aplicativo para registrar treinos, fichas, evolução e dados de perfil.

Antes de publicar, substitua o e-mail de contato abaixo pelo e-mail oficial exibido na ficha do Google Play Console.

Dados que coletamos

  • Dados de conta: e-mail, senha criptografada, nome de exibição e foto de perfil quando informados.
  • Dados de treino: fichas, exercícios, séries, cargas, repetições, sessões, duração e estimativas de calorias.
  • Dados de evolução: registros de peso corporal e histórico de frequência.
  • Dados técnicos essenciais: informações necessárias para autenticação, segurança, funcionamento da API e prevenção de acesso indevido.

Como usamos os dados

Usamos os dados para criar e manter sua conta, salvar seu histórico de treinos, exibir estatísticas de evolução, gerar relatórios compartilháveis e proteger o acesso às suas informações.

Compartilhamento

Não vendemos seus dados pessoais. Seus dados podem ser processados por serviços de infraestrutura usados para hospedar o aplicativo, banco de dados, API e envio de e-mails transacionais, sempre com a finalidade de operar o GymTracker.

Segurança

Senhas são armazenadas de forma criptografada. O acesso aos dados do aplicativo é protegido por autenticação. Mesmo assim, nenhum sistema conectado à internet pode garantir segurança absoluta.

Retenção e exclusão

Mantemos os dados enquanto sua conta estiver ativa ou enquanto forem necessários para operar o serviço. Você pode excluir sua conta dentro do aplicativo em Perfil > Zona de risco > Excluir Conta.

Você também pode solicitar a exclusão pela página pública: Excluir conta e dados.
